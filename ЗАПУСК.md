# Запуск лаборатории — пошагово

> Система собрана, но пока **ничего не покупает** — сначала она набирает данные и меряет
> гипотезы. Ниже порядок действий. Подробности по каждому пункту — `deploy/README.md`,
> карта проекта и все команды — `CLAUDE.md`, почему решения такие — `docs/adr/`.

Все команды с `docker compose` запускаются из папки проекта на сервере.

## Этап А. Поднять систему (один вечер)

Цель: открыть веб-экран и получить ответ бота в телеге. Ключи бирж пока не нужны.

1. **Сервер.** Любой VPS за рубежом: 2 ГБ памяти, 20 ГБ диска, Ubuntu 22.04+.
   Биржи смотрят на IP сервера — если он в ограниченном списке, ветка перейдёт
   в режим «только замер» и скажет об этом (проверка на шаге 6).
2. **Docker.** `curl -fsSL https://get.docker.com | sh`, затем `docker compose version`.
3. **Проект на сервер.** С Windows из папки «Торговля»:
   `scp _sync\crypto-trading-lab-repo.tar.gz root@АДРЕС:~/`, на сервере
   `tar xzf crypto-trading-lab-repo.tar.gz && cd crypto-trading-lab`.
4. **Настройки.** `cp .env.example .env && nano .env`. Для первого запуска — пять строк:
   `POSTGRES_PASSWORD` (придумай), `WEB_USER`, `WEB_PASSWORD`,
   `TELEGRAM_BOT_TOKEN` (@BotFather → /mybots → Trader → API Token),
   `TELEGRAM_ADMIN_ID` (@userinfobot пришлёт число). Остальное оставь пустым.
   `TELEGRAM_API_ID`/`TELEGRAM_API_HASH` (Telethon с my.telegram.org) — необязательно:
   без них каналы авторов читаются через веб-превью `t.me/s/<канал>`, без авторизации.
   **Ключи бирж создавай без права вывода** — с правом вывода система их отклонит.
5. **Запуск.** `docker compose -f deploy/docker-compose.yml up -d --build`.
6. **Проверка.** `docker compose -f deploy/docker-compose.yml ps` — четыре сервиса healthy;
   `... exec worker uv run python -m lab ops status` — какие площадки видны;
   в телеге `/status`. Веб наружу не торчит: со своего компьютера
   `ssh -L 8080:127.0.0.1:8080 root@АДРЕС`, потом `http://127.0.0.1:8080`.

## Этап Б. Данные и первый замер (два-три вечера)

7. **Бесплатные ключи** (регистрация по почте, карта не нужна): Helius → `HELIUS_API_KEY`,
   Alchemy → `ALCHEMY_API_KEY`, Etherscan → `ETHERSCAN_API_KEY`,
   The Graph → `THEGRAPH_API_KEY`, Magic Eden → `MAGICEDEN_API_KEY`,
   OpenSea → `OPENSEA_API_KEY`. Вписал — `docker compose ... up -d`.
8. **История свечей** (ключи не нужны):
   `... exec worker uv run python -m lab data backfill --venue bybit --symbols BTC/USDT:USDT --tf 1h --days 365`.
   Прерывается и продолжается с того же места.
9. **Первая стратегия и замер:**
   `... exec worker uv run python -m lab strategy add --file examples/strategy.yaml`,
   затем `... exec worker uv run python -m lab measure run cex-spot-preset-ema-cross-v1 --days 365`.
   «Не прошла порог» — нормальный и полезный ответ: стратегия уходит на «кладбище»
   с записанной причиной.
10. **Очередь кандидатов.** 30 карточек стратегий и 43 кандидата уже собраны;
    поиск новых — по понедельникам в 6:00, карточки приходят в телегу с кнопками.

## Этап В. Деньги (когда стратегия прошла порог, не раньше)

11. **Ключи бирж без права вывода** — `BYBIT_API_KEY`/`BYBIT_API_SECRET` и т.д.
12. **Горячие кошельки — отдельные, с тестовой суммой:** `SOLANA_HOT_WALLET_KEY`,
    `EVM_HOT_WALLET_KEY`, `TON_HOT_WALLET_MNEMONIC`. Основные кошельки на сервер не класть.
13. **Потолок капитала** — `REAL_CAPITAL_CAP` в `.env` (500–1000 на первую фазу).
    Раскладка по веткам — `config/limits.yaml`: спот и фьючерсы 40% банка / 2% на сделку / до 5×,
    копитрейд 25% / 3% / до 5×, мемы 20% / 10% ветки / без плеча,
    NFT 10% / 25% ветки, Polymarket и акции 5% / 20% ветки.
    Применить без перезапуска: `... exec worker uv run python -m lab ops reload`.

## Дальше — само

**Лестница доверия:** бэктест → бумага → микро → сигнал → полуавтомат → **автомат**.
Вверх — только по замерам, вниз — автоматически, в автомат — только твоей командой.

**Расписание (Самара):** 3:00 бэкап · 4:00 сверка с биржами · 9:00 отчёт в телегу ·
пн 6:00 поиск кандидатов · вс 22:00 переизмерение · вс 22:30 предложение перелива.
Деньги между площадками система не двигает — предлагает, переводишь ты.

**Команды бота:** `/status`, `/halt`, `/resume`, `/queue`, `/limits`, `/promote`, `/retire`.

## Чего система пока не умеет

- **Подпись сделок в сетях не дописана.** Биржи торгуют; покупка мемов на DEX, NFT
  и минты честно отказывают с сообщением вместо имитации торговли.
- **Живая торговля не проверялась ни разу** — в среде сборки нет доступа к биржам.
- **Разбор ответов сетей написан по документации**, не по живым ответам: возможны
  мелкие расхождения формата при первом запуске.

## Обновление

`git pull` (или залить новый архив) и `docker compose -f deploy/docker-compose.yml up -d --build`.
База и скачанные свечи не теряются — они в томах Docker.
