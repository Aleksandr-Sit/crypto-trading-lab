## Что должно заработать

Еженедельный поиск (пн 06:00): OKX public lead traders, Hyperliquid лидерборд (community-эндпоинт с фолбэком на ручной список), Polymarket лидерборд, смарт-мани фиды (Cielo feed, Dune-запросы в квоте), GitHub (публичные стратегии по ключевым словам), Magic Eden launchpad — в очередь `candidates` с отпечатком, без дублей; отклонённые не возвращаются, пока не изменятся существенно. Карточки кандидатов в телегу с кнопками «в замер / отклонить / позже»; «в замер» → `core.measure.run` первого режима по `measure_cost`. Еженедельное переизмерение (вс 22:00) всех живых стратегий на свежем окне → `core.ladder.evaluate`; `valid_until` — без успешного переизмерения N недель → `degraded`. Предложение перелива (вс 22:30): излишек рисковых веток сверх базы → карточка с суммами и кнопкой «перелить»; движение денег — только по подтверждению, и даже внутри площадки. Напоминание G10 после первого запуска: «дополни список кандидатов».
