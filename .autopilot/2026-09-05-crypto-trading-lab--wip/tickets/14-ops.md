## Что должно заработать

`feeds_registry` полноценный: квота/период/счётчик по каждому источнику из `config/feeds.yaml`, health-check по расписанию, прогноз исчерпания при текущем темпе, приоритет и запасной источник; деградация при отказе — пропуск тика/фолбэк/`incomplete`, процесс не падает. Бюджетомер платных сервисов с предупреждением при приближении к `BUDGET_MONTH_USD` (50). Проверка доступности площадок с текущего IP при старте → таблица в `/status` и в дашборде. Суточная сверка журнала с площадками (04:00) → расхождение → `alert`. Ежедневный бэкап базы и конфигов (03:00) в `BACKUP_DIR` с ротацией; инструкция восстановления. Watchdog: сервис не жив 5 минут → `alert`. Горячая перезагрузка конфигов с записью изменений. `deploy/README.md`: развёртывание на VPS одной командой, обновление `git pull && docker compose up -d --build` с автомиграциями. `CLAUDE.md`: раздел «Команды» и «Эксплуатация» (разрешённое изменение).

## Критерии приёмки

- [ ] `feeds_registry`: `use/status/budget`; квоты из `config/feeds.yaml`; прогноз исчерпания; тест на превышение → фолбэк
- [ ] Деградация: тест «источник упал посреди замера» → `incomplete`, процесс жив
- [ ] Бюджетомер: сумма подписок + pay-per-use; предупреждение при 80% и 100%
- [ ] `availability.check_all()` при старте; гео-блок → `down` с текстом; результат в `/status` и `/feeds`
- [ ] `reconcile` job по расписанию, расхождение → `alert` карточка
- [ ] Бэкап: `pg_dump` + конфиги, ротация N дней, `scripts/restore.sh` с проверкой
- [ ] Watchdog: heartbeat каждого сервиса в базе; 5 минут тишины → `alert`
- [ ] `reload`: SIGHUP/команда → `core.risk.reload()` и остальные конфиги; запись изменения
- [ ] `deploy/README.md` на русском: VPS, `.env`, первый запуск, обновление, восстановление; compose `restart: unless-stopped`, автомиграции при старте
- [ ] `CLAUDE.md` дополнен командами эксплуатации (между маркерами autopilot)
