## Что должно заработать

Трекер коллекций: флор, объём, листинги, продажи, держатели — Magic Eden (2 QPS), OpenSea v2 (ключ 7 дней — авто-обновление), Zora, Alchemy NFT API, Tensor (при наличии ключа), Blur — только чтение on-chain. Рейтинг создателей по прошлым коллекциям (флор через 1/7/30 дней после минта, доля успешных). Лента предстоящих минтов (ME launchpad + парсинг календарей) с индексом внимания (формула из спецификации, веса в конфиге). Очередь allowlist-возможностей карточками с дедлайном; отметка «место получено» → allowlist-минт в момент открытия. Ранняя вторичка: покупка по флору в первые минуты по правилу; `decision_latency_ms ≤ 2000`, `confirm_latency_ms` в журнале. Минт-снайпинг как равноправная гипотеза: варианты (приоритетная fee, несколько кошельков, момент отправки) — отдельные стратегии `nft-mint-*` с метриками `mint_attempts/mint_success_rate/mint_cost_failed`. После покупки — частичная продажа на целях, остаток на удержание; роялти/комиссия/газ в издержках; неликвид — флаг с возрастом и правилом снижения цены. Единый `NftMarket` интерфейс.

## Критерии приёмки

- [ ] `NftMarket` протокол; реализации ME/OpenSea/Zora/Alchemy/Tensor(опционально)/Blur(read-only); квоты через `feeds_registry`; OpenSea-ключ обновляется автоматически

- [ ] `upcoming()` — ME launchpad + ≥1 парсер календаря; индекс внимания с весами из `config/nft.yaml`
- [ ] Очередь allowlist: карточка через `bot.send_card("allowlist")`, отметка места, минт по расписанию
- [ ] Стратегия ранней вторички: латентности в журнале; тест «решение за ≤2 с» на фейковом фиде

- [ ] Издержки: роялти, комиссия площадки, газ — по компонентам
- [ ] NFT-исполнители зарегистрированы в `executors.registry`; контрактный тест проходит
