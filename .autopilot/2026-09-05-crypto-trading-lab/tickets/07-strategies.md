## Что должно заработать

Базовый класс стратегии с декларативным манифестом (ветка, площадка, инструменты, параметры, `can_backtest`, стоп, `ttl_s`) и `on_bar/on_event → [Signal]`; каждый сигнал с `decided_at` и `inputs_hash`. Пресеты чужих ботов как стратегии-гипотезы: сетка (spot grid), DCA, фьючерсный грид, «мартингейл с лимитом», трейлинг-трендовая — ≥5, каждая бэктестируется через `core.measure.run` на синтетике. Индикаторы Pifagor и Coinmetrika: версия v0 по публичным описаниям (что известно — в `docs/research/indicators/` из тикета 13; если тикет 13 ещё не сдан — по собственному поиску, с пометкой источников), с явной меткой `[ИНДИКАТОР v0 — по публичным описаниям; v1 — по скрипту пользователя]`; интерфейс для замены на v1 с тестом на эталонных значениях. Журнал публичных сигналов авторов: Telethon читает каналы из `config/authors.yaml`, парсер извлекает инструмент/направление/цель, пишет `signals_public` с `published_at`, оценка по факту через `core.measure`. Адаптер внешних проектов (`external-signal`): webhook + файл + Telegram-канал, формат в `config/external_signals.yaml`. Сигналы по акциям: те же стратегии на дневных свечах из `feeds.stocks` (провайдер по `STOCK_DATA_PROVIDER`: yfinance без ключа / Alpha Vantage), `asset_class: stock`, ступень `signal` навсегда.

## Критерии приёмки

- [ ] `Strategy` базовый класс + `StrategyManifest`; регистрация стратегий по id `<ветка>-<источник>-<слаг>`
- [ ] ≥5 пресетов с параметрами; каждый бэктестится на синтетике и даёт ожидаемый знак результата в понятных условиях (сетка во флэте плюс, в тренде минус и т.п.)
- [ ] `indicators/pifagor.py`, `indicators/coinmetrika.py`: v0 по публичным источникам с ссылками в docstring и меткой-заглушкой там, где логика неизвестна; интерфейс `Indicator.compute(df) -> df`; тест-скелет на эталонных значениях (`tests/strategies/fixtures/indicator_reference.csv` — пустой шаблон с инструкцией)
- [ ] `feeds.social.telegram`: Telethon по `TELEGRAM_API_ID/HASH`, чтение каналов из `authors.yaml`, парсер сигналов с тестами на образцах; без ключей — модуль сообщает «недоступен» и не падает
- [ ] `signals_public` пишутся с `published_at` ДО оценки; оценка форвардом через `core.measure` (режим `forward`, без исполнения)
- [ ] `external-signal`: три транспорта, тест на webhook с примером из `external_signals.yaml`; сигналы попадают в журнал как стратегия `ext-<имя>`
- [ ] `feeds.stocks`: провайдер по конфигу, тикеры из `config/stocks.yaml`, свечи в Parquet; стратегия `asset_class: stock` → сигнал без исполнения
- [ ] Ни одна стратегия не может менять ступень/лимиты (нет доступа к `ladder/risk` — проверка импортов в тесте)
