# 06 — Веб-экран исследователя

**Требования:** R13.2, R13.3, R13.4, R34i, R12.1, R12.2, A02, A03
**Blocked by:** 02, 03
**Зона:** `src/lab/web/`, `tests/web/`
**Волна:** 3
**Status:** ready

## Что должно заработать

FastAPI + Jinja2 + HTMX за HTTP Basic (`WEB_USER`/`WEB_PASSWORD`), слушает `WEB_BIND` (по умолчанию `127.0.0.1:8080`). Экраны: `/` — сводка (капитал по веткам, что прошло/упало за неделю, ожидающие решения); `/strategies` — таблица всех стратегий с одинаковыми колонками метрик, сортировка и фильтры по ветке/ступени/статусу; `/strategies/{id}` — карточка: кривая капитала (SVG без внешних библиотек), метрики с CI95, порог по критериям «значение / порог / ✓✗», журнал сделок, история замеров, переходы; для форвард-только — «бэктест: н/д — нет честной истории» и счётчик накопленного; `/feeds` — источники (квоты, здоровье, прогноз исчерпания, бюджет); `/queue` — кандидаты; `/graveyard` — `failed`/`retired` с причинами. Пустые состояния — с действием. Экспорт CSV сделок.

## Критерии приёмки

- [ ] Basic-auth; без пароля — 401; `WEB_BIND` по умолчанию localhost
- [ ] Пять экранов + карточка стратегии; тексты на русском; тёмная/светлая тема по `prefers-color-scheme`
- [ ] Таблица стратегий: одинаковые колонки для всех веток; ветко-специфичные метрики — отдельный блок в карточке; сортировка/фильтры через HTMX без перезагрузки
- [ ] Карточка: порог по критериям; «недостаточно данных: N из 30»; кривая капитала SVG; CI95 рядом с EV
- [ ] Пустые состояния: реестр пуст → «добавь кандидата или запусти поиск» с двумя кнопками (CLI-команда/ссылка на очередь); нет сделок → текст, не пустая таблица
- [ ] `/feeds` читает `ops.feeds_registry.status()` и `budget()` (интерфейс; фейк в тестах)
- [ ] `/graveyard` с фильтром по причине
- [ ] Экспорт CSV через `core.journal.export_csv`
- [ ] Тесты: маршруты 200 с фикстурами, 401 без auth, пустые состояния, рендер карточки с `incomplete` замером
