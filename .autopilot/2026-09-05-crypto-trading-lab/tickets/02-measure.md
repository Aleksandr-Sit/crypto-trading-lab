## Что должно заработать

На синтетических свечах стратегия с известным ответом (например «купи на первой свече, продай на последней») прогоняется через `core.measure.run(mode="backtest")` и даёт ровно ожидаемый `net_pnl` с учётом издержек по модели площадки; walk-forward делит окно на in-sample/out-of-sample. Тот же движок в режиме `paper` принимает сигналы с `decided_at` и исполняет их по цене хуже мида на модель проскальзывания. Журнал связывает филлы в сделки с издержками по компонентам, считает P&L, экспортирует CSV. Порог из `threshold.yaml` выдаёт по каждому критерию «значение / порог / пройден»; при `n_trades < 30` — статус выборки «недостаточно данных: N из 30», а не нули. Бутстрап даёт CI95 для EV. Бенчмарк BTC B&H за окно — `vs_btc`. Каждый замер — неизменяемый снимок с `data_hash` и `code_version`; повтор на тех же данных даёт тот же результат. Обрыв данных посреди замера → `incomplete` с причиной. Parquet-хранилище: свечи по площадке/инструменту/таймфрейму, партиции по месяцу, чтение DuckDB, загрузка идемпотентна.

## Критерии приёмки

- [ ] Модель издержек: `estimate(venue, intent, book|pool)` и `actual(fill)`; тарифы по площадкам в `config/costs.yaml` (Bybit/OKX/Binance/Hyperliquid taker/maker, DEX-свопы: fee пула + приоритет + газ, NFT: роялти + комиссия площадки); проскальзывание = f(размер/глубина); версия модели в снимке
- [ ] Симулятор: событийный, принимает `Strategy.on_bar`, издержки на каждую сделку, частичные исполнения по лимиту, фандинг по расписанию для перпов; walk-forward с настраиваемыми окнами
- [ ] Режим `paper`: цена исполнения = мид ± модель проскальзывания, сигнал должен иметь `decided_at` раньше бара исполнения — иначе исключение (защита от заглядывания в будущее)
- [ ] Метрики: весь словарь из спецификации, включая `ev_ci95` (бутстрап 1000), `vs_btc`, `costs_pct` с разбивкой; ветко-специфичные — `None` с причиной
- [ ] Порог: `threshold(metrics, branch)` → объект по критериям; `n_trades<30` → `insufficient`
- [ ] Журнал: `record_signal/record_fill/close_trade`, связывание FIFO, P&L realized+unrealized, `export_csv`
- [ ] `reconcile(venue, fills_from_venue)` — сравнение с журналом, расхождение > порога → событие `ReconcileMismatch`
- [ ] Снимок замера: `data_hash`, `code_version` (git sha), параметры; повторный `run` идемпотентен; `incomplete` при обрыве данных
- [ ] Parquet-хранилище: `data.store.write(venue, instr, tf, df)` идемпотентно; `read(...)` через DuckDB; бэкфилл с прогрессом и возобновлением (тест на прерывание)
- [ ] `measure_cost` и `can_backtest` у кандидата вычисляются из манифеста ветки
- [ ] Тесты на синтетике: известный ответ ± издержки; тест «заглядывание в будущее» падает; тест порога на границах
