## Что должно заработать

`docker compose up -d` поднимает Postgres и три пустых сервиса (worker/bot/web) с healthcheck; `uv run alembic upgrade head` создаёт схему из спецификации; `uv run python -m lab strategy add --file examples/strategy.yaml` кладёт стратегию в реестр со статусом `candidate`; повторное добавление того же — отказ «уже есть»; неполный манифест — ошибка с именем поля и сохранённый черновик. При старте любого сервиса печатается список площадок: «подключена» / «только данные (ключ пуст)» по именам из `.env.example`; ключ с правом вывода — предупреждение и отказ использовать. Протоколы `Feed`, `Executor`, `Strategy`, `NftMarket` и типы `OrderIntent`, `Signal`, `Costs`, `Health`, `StrategyManifest` зафиксированы в `contracts/` и покрыты тестами на сериализацию. Конфиги `limits.yaml` (таблица лимитов из спецификации), `threshold.yaml`, `schedule.yaml` читаются pydantic-моделями.
