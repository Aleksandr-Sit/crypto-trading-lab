## Правила проверки (объявлены ДО прогона)

**Данные.** Binance spot BTCUSDT и ETHUSDT, дневные свечи (граница суток 00:00 UTC),
17.08.2017 … 10.10.2026. Кэш вне репо: `Торговля/lab-data/brandt/`. Дополнительно (только для
справки, не в вердикт): BTC Bitstamp 2013–08.2017 — более ранняя эпоха.

**Фигура — формальное приближение.** Классические фигуры Brandt рисует на глаз; общая у
горизонтальных (прямоугольник, восходящий треугольник, линия шеи «двойного дна» и «головы и
плеч») — граница, которой цена касалась не один раз. Для лонга в день `t`:
* окно — `N` дней до `t`; граница `B` — максимум хаев окна, `L` — минимум лоев;
* касание — день окна с хаем ≥ `B − 0.5·ATR14`; первое и последнее касание разнесены
  не меньше чем на `N/4` дней;
* пробой — закрытие дня `t` выше `B`;
* шорт — зеркально (граница по лоям, закрытие ниже).

`N` ∈ {28, 56, 84} (4 / 8 / 12 недель); **главная клетка — 56.**

**Вход** — открытие дня `t+1` (сигнал известен после закрытия). Одна позиция на инструмент:
сигнал при открытой позиции пропускается. Если открытие уже за стопом LDR — сделка не
открывается (печатается число таких).

**Ведение позиции — по записке 06.12.2023**, позиция делится пополам:

| | торговая половина | позиционная половина |
|---|---|---|
| начальный стоп | LDR: лой дня пробоя, если не меньше половины бара ниже `B`, иначе лой последнего полного дня фигуры (`t−1`) | ниже из двух: лой `t−1` и LDR; со второго дня сделки — LDR |
| безубыток | «как можно скорее» → после закрытия ≥ вход + 1R стоп не ниже входа | — |
| 3DTSR | сразу | только пока его срабатывание дало бы убыток (уровень ниже входа) |
| цель | измеренный ход `B + (B − L)` | V1 (главная) — та же цель; V2 — без цели |
| выход по MA8 | — | если половина в плюсе и цели нет: MA8 развернулась вниз и полный бар ниже MA8 → стоп за лоем этого бара (новый такой бар двигает уровень) |

3DTSR: «день хая» — наибольший хай с входа; «день установки» — первый после него день с
закрытием ниже лоя дня хая; выход — пробой лоя дня установки. Новый хай сбрасывает установку.
Пункт C («подтягивать стоп за малые коррекции») не формализуется и не моделируется.

Исполнение: стоп — по `min(open, стоп)` (гэп), цель — по `max(open, цель)`; стоп и цель в
один день — считается стоп (в худшую сторону). Издержки — **0.20% за круг** (тейкер плюс
проскальзывание стоп-ордеров). Фандинг не учитывается: лонг — спот, шорт на перпе в основном
фандинг получает, то есть без него шорту хуже, не лучше.

**Мера сделки** — лог-доходность позиции (среднее двух половин) в %, за вычетом издержек;
рядом — в R (R = вход − LDR). Счёт с риском 1% на сделку (позиция ≤ ×3 депозита — предел
плеча владельца) и BTC «купил и держи» — справочно.

**Контроли.**
* **К1 (главный) — случайное время, те же выходы.** Для каждой сделки — случайный день того же
  инструмента в ±365 днях; вход по его следующему открытию, стопы и цель — на тех же
  относительных расстояниях, что у настоящей сделки, 3DTSR и MA8 — по данным. Вопрос: несёт ли
  информацию ВРЕМЯ входа по фигуре, или плюс даёт трендовый выход в растущем рынке (ротация
  уже показала, что трендовый выход у BTC работает, `rotation-2026-09-14.md`). 2 000 наборов.
* **К2 — простой пробой Donchian** того же `N` без условия касаний, те же выходы — не сводится
  ли «фигура» к пробою максимума (справочно).

**Шум** — по блокам: сделки BTC и ETH, открытые в один календарный месяц, — один блок
(`block_stats`: среднее по сделкам, кластерная ошибка по суммам блоков).

**Вердикт по каждой стороне (лонг и шорт отдельно), главная клетка N=56, V1.** `passed` — если
выполнены все четыре:
1. средний итог сделки > 0 и больше своих 2σ;
2. избыток над К1 больше своих 2σ **и** доля наборов К1 со средним не хуже сделок ≤ 2.5%;
3. плато: избыток над К1 > 0 при всех трёх `N`;
4. годы: избыток > 0 не меньше чем в половине лет с ≥ 2 сделками, и ни один год не даёт больше
   половины суммарного избытка.

Иначе `failed`. Если выполнен п.1, но не п.2 — запись «плюс даёт выход по тренду, а не фигура».

Заранее: сделок будет мало (одна позиция на инструмент, 8-недельные фигуры — порядка десятков
на сторону), и `failed` по шуму — это «эффекта, различимого на 9 годах двух монет, нет», а не
«правило вредно».
