## 2. Что в CryptosMX оказалось полезным, а что нет

| Источник | Что дал |
|---|---|
| сигналы закрытого канала (277 по цене) | шум: +6.6 ± 6.9 п. против случайного входа |
| профиль Bybit | сделки скрыты, копирующие в сумме −486 тыс. USDT |
| **открытая история Binance, 279 исполненных сделок** | **автомат**: покупка в минуту обвала альт-перпа, цель ≈+1.5%, выход по таймеру 7 мин → правило словами → проверка 2021–2024 (лимитка прошла) → бумажная торговля |

Значит, «трейдер как CryptosMX» — это не «учит» и не «в плюсе», а два признака сразу:

* **видны ИСПОЛНЕННЫЕ сделки с точным временем** (открытый копитрейдинг, ончейн), а не прогнозы;
* **в сделках повторяется механизм**: выход по таймеру, одна и та же цель, вход в минуту
  измеримого события. Такой механизм восстанавливается по сделкам × минутным свечам и
  проверяется на годах истории без участия самого трейдера.

Результат трейдера не критерий отбора: перенос результата не подтвердился четыре раза. Трейдер —
источник гипотезы, правило проверяет лаборатория.

## 4. Подпись автомата: признаки и пороги (объявлены до пилота, 24.10.2026)

По закрытым позициям окна (до 200 последних в пилоте). Доходность сделки — по средним ценам
входа и выхода со стороной, без комиссий: для подписи этого хватает.

| Признак | Как считается | Порог |
|---|---|---|
| **T — таймер на убытках** | доля убыточных сделок в модальной корзине длительности ±1 соседняя (корзины по 5%) | ≥ 0.40, мода ≥ 30 с, убыточных ≥ 10 |
| **A — таймер на всех** | то же по всем сделкам | ≥ 0.40, мода ≥ 30 с |
| **P — одна цель** | доля прибыльных сделок в модальной корзине доходности ±1 (корзины по 0.1 п.п.) | ≥ 0.40, прибыльных ≥ 20 |
| **M — одна минута часа** | доля входов в самую частую минуту часа (ровно — 0.017) | ≥ 0.20 |

Допуск к подписи: закрытых сделок ≥ 30; не больше 200 сделок в сутки (выше — маркет-мейкер или
HFT: преимущество в скорости, скопировать нельзя — `copytrading-2026-09-12.md`).
Результат трейдера в отбор не входит; сетки и мартингейл подпись тоже дадут (одна цель) —
отличаются при ручном разборе.

**Положительный контроль — CryptosMX** (`5064581361618552064`, 249 закрытых сделок за 117.5 дня):
T = **0.65 на 420 с (7.0 мин)**, цель-мода +1.5% (P = 0.25), 43 монеты, только лонг, плечо ×1,
2.1 сделки в сутки. Подпись T срабатывает — детектор известный автомат узнаёт.

истории, которых трейдер не видел, с вердиктом, объявленным до прогона, а его собственный
результат в отбор не входит вовсе.

## 8. Полный скан Binance: 3 740 портфелей с меткой API (24–25.10.2026)

### 8.1 Как устроен скан

Скрипт — `scripts/open_automata.py` (stdlib; подкоманды `list`, `tradfi`, `probe`, `scan`,
`review`; тесты — `tests/scripts/test_open_automata.py`). Признаки и пороги — те же, что в пилоте
(раздел 4), код признаков перенесён без изменений: на файле пилота скрипт даёт те же 43 / 18
(T 1, A 1, P 9, M 10), на CryptosMX — те же T = 0.65 на 420 с. Положительный контроль перед
запуском прошёл.

* весь пул с меткой API из `bn_list.jsonl` (снимок 24.10), порядок случайный (seed 20261024) —
  оборванный скан всё равно случайная выборка; до 200 последних закрытых позиций на портфель;
* строка в `bn_scan.jsonl` сразу после портфеля, перезапуск продолжает с места; ошибки сети —
  в `bn_scan_err.jsonl` и повторяются при следующем запуске;
* сырые закрытые позиции активных портфелей — `bn_scan_pos.jsonl`: окно истории у Binance
  скользящее, для разбора по одному эти же сделки позже уже не скачать;
* перпы акций, товаров и валют отличаются не по буквам символа, а по справочнику биржи:
  `fapi/v1/exchangeInfo`, `contractType = TRADIFI_PERPETUAL` — 225 символов на 24.10
  (`bn_tradfi_symbols.json`; акции США, Кореи, Гонконга, золото, нефть, `CSOP…2L`).

### 8.2 Правила разбора — объявлены 24.10 во время скана, до взгляда на его итог

Калибровка — только по пилоту. Доходность в разборе не участвует: в файлах скана её нет.

| Класс | Условие (первое совпадение выигрывает) | Куда |
|---|---|---|
| `tradfi` | ≥ 50% закрытых позиций на `TRADIFI_PERPETUAL` | отдельной строкой |
| `martingale` | P и прибыльных ≥ 97% (усреднение без стопа, закрыт для лаборатории) | отдельной строкой |
| `timer_T` | T — таймер на убытках (тип CryptosMX) | **шорт-лист** |
| `timer_A` | A без T — таймер на всех | **шорт-лист** |
| `event_M` | M и больше половины входов в одну минуту часа — вход по часам свечи (в пилоте такие 65–99%, слабые 21–31%) | **шорт-лист** |
| `M_weak` | M, доля минуты < 0.50 | отдельной строкой |
| `P_other` | P без мартингейла (скальп, одна цель) | отдельной строкой |

* **Порядок шорт-листа:** `timer_T` по доле таймера убытков, затем `timer_A` по доле таймера
  всех, затем `event_M` по доле минуты; при равенстве — больше сделок, затем `pid`. Чище подпись —
  проще восстановить правило; это не ранг по качеству.
* **Копии одного бота сворачиваются:** портфель, у которого ≥ 50% входов (символ, сторона,
  минута) совпадают с более ранним в очереди (оба ≥ 10 входов), идёт в строку того, в колонку
  «копии».
* **CryptosMX** — контроль, не находка: в шорт-лист не входит. **`5256963119481330945`** (кандидат в
  «зеркало», раздел 5) открывает очередь разбора при любом классе.
