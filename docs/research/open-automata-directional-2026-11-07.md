# №39 捕捉单边上涨下跌: проверка подписи таймера

Портфель `5095694990932973056`, следующий по §8.5. Дата 07.11.2026.
Отбор по механике, без отбора по прибыли. Профиль не содержит описания правила.

## План до дальнейшего анализа

Сначала проверить предпосылку «независимые выходы через 39 минут».
В сохранённом скане 200 строк (199 с closed); 157 позиций Long ×5 открылись
22.08 в 05:01:24.930–05:11:11.457 UTC, а closed всех попал в интервал
05:42:49.188–05:42:49.227 (39 мс). Их удержания различаются на 586.527 с.
Общее время закрытия способно породить моду длительности без индивидуального
таймера: нельзя принимать значение детектора за восстановленное правило.

До ценового анализа: сгруппировать полную доступную историю по секундным
меткам закрытия, вывести размер крупнейших групп и их долю в скане, диапазоны
входа/длительности; пересчитать ту же подпись после исключения крупнейшей
группы как проверку зависимости результата от одного эпизода. Это анализ
чувствительности детектора, не подбор нового таймера или торгового правила.
Не интерпретировать общую метку closed как доказательство ручного выхода,
ликвидации или принудительного закрытия без ордеров и отдельного свидетельства.

Сверить доступные ордера с позициями: покрытие, объёмы, обе стороны,
частичные закрытия. Новая лента содержит лишь 52 исполнения за сентябрь–октябрь;
августовский эпизод ими не подтверждается. Первичный fetch позиций завершился
ошибкой null data, результат не сохранил. Новый сбор архивирует каждую страницу,
ошибки и факт неполноты. Текущий total=1686 против 1915 в старом скане — разные
скользящие окна, не доказательство пропажи сделок. Уже замечены точные дубли
между страницами при большом числе одинаковых closed; не выдавать число
полученных строк за число уникальных позиций.

Если независимый повторяющийся механизм не восстановлен, статус
`rule_unidentified`, P&L н/д. Для теста прибыли сначала нужны конкретные
правила, ≥90% воспроизведения при реконструкции и ≥80% на отдельном ещё
не просмотренном периоде (≥20 входов), объяснённые исполнения и издержки.
Ценовые признаки, индикаторы и бэктест заменителя на данном этапе не нужны.

## Итог: подпись зависит от общего закрытия пачки

**`rule_unidentified`, P&L н/д.** Индивидуальный повторяющийся выход через
39 минут не восстановлен. Общие метки закрытия корзин подтверждаются на
позиционных данных; способ и причина августовского закрытия неизвестны.
Это не финансовый `failed` и не доказательство отсутствия другого автомата.

### Полнота

Первый проход по 50 строк: 1686 строк, 1669 уникальных positionId.
Второй по 200: 1686 строк, 1684 уникальных. Две дополнительные страницы
по 199 строк (№4–5) восполнили оставшиеся два ID. Объединение содержит
**1686/1686** доступных позиций: 1685 закрытых и одну частично закрытую.
Во всех ответах total=1686. Точный механизм повторов/пропусков при пагинации
не установлен; крупные группы одинаковых closed делают гипотезу нестабильного
порядка при равных ключах правдоподобной, но серверный порядок неизвестен.

Все 200 записей старого скана найдены без изменений. Между текущими проходами
менялось только roi одной частично закрытой BTC-позиции, остальные поля
совпали; варианты сохранены в raw. Полнота относится к текущему окну API,
не ко всем 1915 позициям из счётчика 24.10 и не к открытым позициям без закрытий.

Отдельные ответы архивированы в `directional_pages_2026-11-07/`,
`directional_pages200_2026-11-07/`, `directional_pages199_2026-11-07/`.
Ошибки, включая 90801003 и неудачную проверку размера страницы, сохранены.
API ограничил пробный pageSize=2000 фактическими 200 строками.
Исходные неполные агрегаты fetch не заменяют объединённый снимок
`directional_5095694990932973056_merged_2026-11-07.json`.

### Проверка той же подписи, без подбора

Использована исходная функция `features` из `scripts/open_automata.py`,
а не новый допуск: логарифмическая корзина длительности с шагом 5%, модальная
корзина и ±1 соседняя. Поэтому подпись «39 минут» уже изначально означает
широкую группу похожих длительностей, а не точное равенство таймеру.
Сторона и изменение средней цены используются только для исходного разделения
таймера убытков/всех; прибыльность не проверяется.

| Старый скан | 199 | 0.53 | 0.48 |

Мода старого скана 2334 с; вне пачки прежняя 39-минутная подпись не сохраняется.
Не следует трактовать 157 связанных закрытий как 157 независимых подтверждений.

В полной доступной истории августовская группа скана расширилась до 158
позиций (закрытия 40 мс). Она не единственная. Крупнейшие группы по секунде:

Все три группы — Long, на разных контрактах внутри каждой. Видна общая метка

позиционному API нельзя отличить реальное синхронное исполнение от присвоения
общего времени при обработке исторических записей. Августовских ордеров нет.

### Доступные исполнения

52/52 ордера 12.09–24.10 однозначно сопоставлены 26 позициям: 36 LIMIT,
16 MARKET. Входы все LIMIT; выходы — LIMIT или MARKET. Объёмы сходятся:

расхождение средних цен с позициями 0.00000008. Ни один из этих ордеров
не относится к августовской пачке. Нельзя переносить тип исполнения поздних
сделок на август или объяснять им механизм общего закрытия.

решений/причин закрытия или независимым описанием стратегии. Срок и сигнал
