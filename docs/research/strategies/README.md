# Каталог стилей: что лаборатория уже измерила

Состояние на 26.09.2026. Это п.4 плана `docs/research/traders-plan.md` — «зафиксировать»
владельца: какие стили торговли проверены, чем кончилось и где разбор. Сами карточки
стратегий лежат рядом (`<ветка>-<слаг>.md`), этот файл их не заменяет: код читает карточки
по имени, а этот файл не читает никто, кроме людей.

**Как читать.** Поле `status` в карточках у всех `hypothesis` — после замера его никто не
обновляет. Вердикт живёт в двух местах: ступень и последний замер в базе (реестр) и прямые
проверки скриптами (`signal_check`, `price_signal_check`, `calendar_effects` и т. п.) в
исследованиях. Статус реестра `candidate` на ступени `backtest` значит «записана и не
поднята», а не «прошла». Свежий срез реестра одной таблицей:

```
bash scripts/last-measurements.sh [подстрока id]
```

**Как обновлять.** Закрыли исследование — строка в свой стиль и, если вердикт стиля
сдвинулся, правка сводной таблицы. Цифры брать из разбора, а не пересказывать по памяти.

## Что это значит для гибрида (п.5 плана)

По режимам рынка на сегодня есть:

| Режим | Чем покрыт | Статус |
|---|---|---|
| рост | ротация держит BTC | `paper`, ответ после 14.12.2026 |
| падение | ротация уходит в золото или кэш; шорт листингов (от фазы не зависит) | ротация — `paper`; листинги — нужна лента и решение владельца |
| боковик | **ничем** | сетки, DCA-боты и перенос ниже безрисковой; трейдеров боковика не выделить |
| любой, внутри суток | гашение первого часа UTC | замер `failed`: круг 0.30% съедает +0.26; нужен замер настоящего круга |
| любой | премия волатильности | нужен исполнитель опционов |

Распределителю по режимам сейчас почти нечего распределять: одна стратегия на бумаге,
одна прошедшая без ленты данных, один эффект, который на модели издержек лаборатории
не окупает круг. Порядок, в котором это
расширяется, — п.5 плана и решения владельца.
