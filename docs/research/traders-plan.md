## Разовый прогон непроверенного скрипта: `scripts/lab-oneoff.sh` — ГОТОВО 26.09.2026

Коммит `26fdc4d`. С рабочей машины (Git Bash), из корня репозитория:

```
bash scripts/lab-oneoff.sh [--lint | --lint-only] [--trades-sample N] <скрипт.py> [ещё .py…] \
     [-- <аргументы запуска>] [-- <аргументы следующего запуска>…]
```

Сам находит и отправляет модули из `scripts/`, которые импортирует скрипт; каждый блок
после `--` — отдельный запуск в том же контейнере, до первой ошибки. Линт с тёплым
окружением — 12 с. Долгие прогоны — не сюда, а в `run-detached.sh`.
