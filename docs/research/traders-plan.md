## Порядок работы и состояние

1. **Замер вперёд в кроне — ГОТОВО 26.09.2026.** `copytrade_monthly.sh` починен (три тихих
   дефекта, см. CLAUDE.md), в кроне Hostkey `10 5 1 * *` с меткой `lab_copytrade_monthly`.
   Итог копится в томе: `copytrade/forward.jsonl`. Снимки: 12.09 (топ-200, без плеча),
   26.09 (весь рейтинг, с плечом). Первый осмысленный ответ — прогон 01.11.2026.
2. **Плечо ×2–3 — ИДЁТ.** `scripts/leverage_persist.py` (коммит `20b8528`). Запущено
   26.09 ~14:00 отвязанно: `run-detached.sh traders "bash /root/traders-chain.sh"` —
   ежемесячный прогон → `regime_persist` на свежих кривых → сбор сделок → расчёт плеча.
   Лог: `ssh vps-trader 'tail -60 /root/traders.log'`, конец — строка `ГОТОВО код=N`.
   После `ГОТОВО` — `git pull` на сервере: коммит с этим планом туда не подтягивался,
   пока цепочка исполняла `copytrade_monthly.sh` (bash читает скрипт по ходу работы).
   Сделки сохраняются в `copytrade/fills/<адрес>.jsonl.gz`; отказавшие счета докачиваются
   повторным `--stage fills`. Результат записать в `traders-regimes-2026-09-26.md`
   (раздел «Плечо») и сравнить свежий `regime_persist` с цифрами от 12.09-кривых.
3. **«Толпа как сигнал» — КОД НЕ ПРОВЕРЕН, НЕ ЗАКОММИЧЕН.** `scripts/crowd_flow.py`
   (четыре стадии: scan → classify → flow → check) по потоку `wake`
   (`/opt/wake/data/trades`, только чтение; не пересекается с `wake`: там лидеры
   и секунды, здесь классы по плечу и часы). Линт проходил до правки про разрывы.
   Следующий шаг — пробный прогон на срезе из пяти часов, уже лежащем на сервере:
   ```
   ssh vps-trader 'cd /opt/crypto-trading-lab && docker compose -f deploy/docker-compose.yml \
     run --rm --no-deps -T -v /opt/crypto-trading-lab:/src -v /tmp/lint:/lint -w /src \
     --entrypoint sh worker -c "P=/app/.venv/bin/python; \$P /lint/crowd_flow.py --stage scan \
     --trades /lint/trades --root /lint/root && …classify --top 15 … && …flow … && \
     …check --window 1 --horizons 1 --tail 0.2 --root /lint/root" </dev/null'
   ```
   (сначала `scp scripts/crowd_flow.py scripts/copytrade_screen.py vps-trader:/tmp/lint/`).
   Проверить печать «доля пассивных у 10 самых частых»: у маркет-мейкеров должна быть
   высокой — иначе смысл поля `side` перевёрнут. Потом коммит и полный прогон:
   scan и flow — отвязанно, по ~30–60 мин; classify — ТОЛЬКО после окончания цепочки
   из п.2 (общий порог частоты Hyperliquid на IP). Окно — 43+ суток одного режима:
   находка = довод копить, а не кодировать.
4. **Каталог стилей трейдеров с вердиктами** — `docs/research/strategies/` (это «зафиксировать»
   владельца): тренд, возврат к среднему, боковик, перенос/фандинг — что про каждый уже
   измерено лабораторией, со ссылками. Не начато.
5. **Гибрид = распределитель по режимам поверх лестницы.** Не хватает распределителя и
   прошедших стратегий (сейчас одна — ротация золото/BTC, заморожена вперёд с 14.09).
   Потолок плеча ×3 в `config/limits.yaml` (сейчас `cex-perp` и `copy` — ×5) — поставить
   вместе с распределителем, по решению владельца. Не начато.
