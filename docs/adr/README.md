# Записи об архитектурных решениях (ADR)

Здесь лежат решения, которые дорого пересматривать, и причины, по которым они приняты.
Спецификация сборки (`.autopilot/`) живёт вместе со сборкой; эти записи — то, что должно
её пережить. Источники — `spec.md` и `manifest.md` той же сборки; где причина в источниках
не записана, это сказано в самой записи, а не додумано.

Запись не меняется задним числом. Если решение пересматривается — пишется новая запись
со статусом «принято», а старая получает пометку «заменено NNNN».

## Что осталось незаписанным

- **Чистый лист вместо слияния с `crypto-trader` и `solana-smart-money`** (R01, ответ В16).
  В источниках зафиксирована только формулировка решения — «чистый лист с адаптерами»;
  причина выбора не записана, поэтому отдельная запись не составлена: обосновать её
  можно было бы только домыслом. Действующая форма решения: старые проекты подключаются
  как внешние источники сигналов через адаптер (`external-signal`, R01.3).
- **Отказ от специализированной time-series-СУБД** — см. раздел «Что рассматривали и
  отвергли» в [0008](0008-hranenie-postgres-i-parquet.md): вариант в источниках не
  обсуждался.
- **Почему стоп именно под каждую стратегию, а не общий** — см. «Контекст» в
  [0005](0005-stop-pod-kazhduyu-strategiyu-i-raskladka-kapitala.md): это прямое указание
  пользователя (G04), мотив им не назван.
