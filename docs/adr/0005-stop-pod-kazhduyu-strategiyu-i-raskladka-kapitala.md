# 0005. Стоп — под каждую стратегию свой; общего автоматического стопа нет; капитал разложен по веткам с потолком реальных денег

- Статус: принято
- Дата: 2026-09-07
- Требования: G04, G04.1, R30i, R30i.1–R30i.7; основания — ответы В1, В9а, В19

## Контекст

Пользователь сказал прямо: «не общий стоп, а под каждую стратегию свой» (G04). Причина
такого выбора в источниках не записана — зафиксирована только сама формулировка,
поэтому ниже описаны следствия решения, а не приписанный ему мотив. Рядом два числа
пользователя: реальных денег в первой фазе $500–1 000 (В1) и раскладка капитала по
веткам 40/25/20/10/5, принятая ответом «подходит» (В9а). Без раскладки одна ветка
(мемы или NFT) съедает банк раньше, чем её успеют замерить.

## Решение

Стоп — поле стратегии (`stop_json`: дневной и/или на просадку). Пробой отменяет ордера
именно этой стратегии, переводит её в `degraded` и шлёт уведомление; соседние стратегии
продолжают работать. Общего автоматического стопа нет; вместо него — ручной `/halt` и
`/resume` с двойным подтверждением. Поверх стопов стратегий у каждой ветки есть
страховочный стоп, останавливающий только свою ветку: −5%/день для `cex-spot + cex-perp +
dex-perp` и `copy`, −20%/день для `meme`, −30%/неделю для `nft`, −20%/неделю для
`prediction + rh`. Доли банка и лимиты — `config/limits.yaml` (40% / 25% / 20% / 10% / 5%,
максимум на сделку и плечо по таблице), горячая перезагрузка с записью, кто и когда
менял. Размер позиции считается от текущего капитала ветки, а не от стартового.
`REAL_CAPITAL_CAP` ограничивает сумму живых позиций и балансов на ступенях `micro` и
выше; всё сверх потолка — только бумага. Из двух ограничений (стратегия и ветка)
действует более строгое.

## Последствия

Стало легко: взрыв одной гипотезы виден и локализован — останавливается она, а не
лаборатория. Ветка с недоступной площадкой не «освобождает» свою долю другим:
берётся последний известный баланс с пометкой «устарел» (R30i.5).

Цена: при общей причине сбоя — плохие данные, сбойный фид, обвал рынка — стопы
срабатывают по одному, и убыток успевает пройти по нескольким стратегиям и веткам,
прежде чем оператор нажмёт `/halt`. Это прямой выбор пользователя, а не недосмотр:
цена за то, что одна плохая стратегия не гасит остальные. Потолок реального капитала
означает, что даже прошедшая порог стратегия не масштабируется, пока потолок не поднят
руками. Каждая стратегия обязана нести стоп в манифесте — без него её нельзя завести.
Расчёт размера от текущего капитала ветки делает позиции меньше после просадки — выход
из ямы медленнее, чем вход в неё.
Теперь нельзя: автоматически перелить деньги между площадками при просадке (В19 —
только по подтверждению); поставить одну «аварийную кнопку», которая сама решит,
что пора всё остановить.

## Что рассматривали и отвергли

- **Общий стоп по счёту.** Отвергнут пользователем дословно (G04). Он гасит и те
  стратегии, которые в этот день работали, и обнуляет их замеры.
- **Полное отсутствие страховочных стопов ветки.** Тогда одна ветка выбирает долю
  соседних раньше, чем сработает её собственный лимит на сделку.
- **Единые лимиты для всех веток.** Мемы без плеча и перпы с плечом ≤5× не описываются
  одной строкой; отсюда таблица В9а с разными горизонтами (день против недели).
- **Автоматический перелив прибыли в спокойные ветки.** В19: система только предлагает
  сумму, деньги двигает оператор кнопкой (G05, G05.1).
